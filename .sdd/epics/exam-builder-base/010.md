# T010: Admin user management

## Context

Vì hệ thống không có self-registration (quyết định khóa từ prd-rethink — giao đề tường minh yêu cầu tài khoản do admin kiểm soát), đây là con đường duy nhất để tạo tài khoản `user`. T012 (exam assignment) phụ thuộc vào task này vì assignment cần user đã tồn tại.

## Description

Endpoint `POST /users` chỉ admin gọi được, tạo tài khoản với role `user`. Không có endpoint đăng ký công khai nào tồn tại trong hệ thống.

## Implementation Steps

1. `app/application/use_cases/create_user.py`: use case nhận `email, password, role` (mặc định role=`user` — admin không tự tạo admin khác qua endpoint này ở v1, tránh leo thang không kiểm soát), hash password (dùng `hash_password` từ T003), lưu vào DB.
2. `app/api/v1/routers/users.py`: `POST /users` với dependency `Depends(require_role("admin"))`, gọi use case, trả `201` với thông tin user (không trả password_hash).
3. Validate email không trùng — trả `409` nếu email đã tồn tại.

## Acceptance Criteria

- **FR-2 / scenario:** Given admin đã đăng nhập, when `POST /users` với email+password hợp lệ, then tài khoản được tạo, response 201.
- **FR-2 / scenario:** Given user thường (role=`user`) đã đăng nhập, when gọi `POST /users`, then response 403.
- **FR-2 / scenario:** Given không có token nào, when gọi `POST /users`, then response 401.
- **FR-2 / scenario:** Given email đã tồn tại trong hệ thống, when admin tạo user với email đó, then response 409.

## Interface Contract

**Receives from T003:** `require_role("admin")` dependency, `hash_password` helper.
**Produces:** User records trong DB mà T012 (assignment) và T020 (submission, results) dùng làm `user_id`.

## Tests to Write

- Admin tạo user thành công → 201, password_hash không xuất hiện trong response.
- Non-admin tạo user → 403.
- Không có token → 401.
- Email trùng → 409.

## Technical Details

Không có route đăng ký công khai — verify bằng cách liệt kê toàn bộ route đã đăng ký trong OpenAPI schema (`/openapi.json`) và xác nhận không có route nào ngoài `/auth/login`, `/auth/refresh` không yêu cầu auth.
