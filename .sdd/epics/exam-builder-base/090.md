# T090: Verification — full epic

## Context

Task cuối cùng, bắt buộc, chạy sau khi toàn bộ 7 task khác đã đóng. Mục tiêu: xác nhận epic hoạt động end-to-end đúng như PRD mô tả, không chỉ từng task riêng lẻ pass test của nó.

## Description

Viết 1 test tích hợp end-to-end đi qua toàn bộ luồng nghiệp vụ (đăng nhập admin → tạo user → tạo câu hỏi kèm ảnh → ghép đề → giao đề → user đăng nhập → nộp bài → xem kết quả cả 2 phía), cộng với việc chạy lại toàn bộ test suite và smoke test Docker Compose.

## Implementation Steps

1. `tests/integration/test_e2e_flow.py`: viết 1 test class đi tuần tự qua toàn bộ luồng — mỗi bước dùng response của bước trước (login → user_id → question_id → exam_id → assignment_id → submission_id).
2. Chạy toàn bộ test suite: `pytest tests/ -v --tb=short`, xác nhận 100% pass, không có test bị skip không lý do.
3. Chạy smoke test Docker Compose từ môi trường sạch (xóa volume cũ, `docker-compose up -d`, đợi healthcheck, `curl` health endpoint).
4. Đối chiếu từng dòng trong Traceability Matrix (`epic.md`) — với mỗi FR/NFR, xác nhận có ít nhất 1 test tương ứng thực sự tồn tại và pass (không chỉ được nhắc tên trong task file).
5. `grep -rn "TODO\|FIXME" app/` — xác nhận không còn code chưa hoàn thiện.

## Acceptance Criteria

- **All FR/NFR / scenario:** Given toàn bộ 7 task đã đóng, when chạy `pytest tests/ -v`, then 100% test pass.
- **NFR-4 / scenario:** Given môi trường Docker sạch, when `docker-compose up -d`, then health check trả 200 trong 60s (SC-5).
- **All FR / scenario:** Given luồng end-to-end (tạo user → câu hỏi → đề → giao đề → nộp bài → kết quả), when chạy `test_e2e_flow.py`, then toàn bộ bước thành công, điểm số khớp đáp án cấu hình (SC-1).

## Tests to Write
