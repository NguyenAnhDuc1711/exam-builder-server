# T011: Question bank CRUD + Cloudinary image upload

## Context

Ngân hàng câu hỏi là nền cho việc ghép đề (T012). NFR-2 yêu cầu lỗi Cloudinary không được chặn việc tạo câu hỏi text-only — đây là lý do `ImageStoragePort` tồn tại thay vì gọi SDK Cloudinary trực tiếp trong route handler (AD-3).

## Description

`POST /questions` tạo câu hỏi trắc nghiệm (text + ≥2 lựa chọn, đúng 1 đáp án đúng), ảnh tùy chọn upload qua Cloudinary đằng sau `ImageStoragePort`. Validate MIME-type/kích thước file trước khi upload (WARN-3, từ plan-review).

## Implementation Steps

1. `app/application/ports/image_storage.py`: interface `ImageStoragePort` với `upload(file: bytes, content_type: str) -> str | UploadError`.
2. `app/infrastructure/storage/cloudinary_service.py`: implement port bằng Cloudinary SDK, catch mọi lỗi SDK và convert thành `UploadError` (không để exception thô của SDK lọt ra ngoài).
3. `app/application/use_cases/create_question.py`: nhận `text, options: list[{text, is_correct}], image: bytes|None`. Validate: đúng 1 `is_correct=True` trong options (reject 400 nếu 0 hoặc >1). Nếu có image: validate MIME-type (`image/png`, `image/jpeg`, `image/webp` — reject 400 nếu khác) và kích thước ≤5MB (reject 400 nếu vượt) TRƯỚC khi gọi `ImageStoragePort.upload`. Nếu upload thất bại (`UploadError`), lưu câu hỏi với `image_url=None`, trả response 201 kèm field `image_upload_warning`.
4. `app/api/v1/routers/questions.py`: `POST /questions` (`require_role("admin")`), `GET /questions` (list, `require_role("admin")` — chỉ admin quản lý ngân hàng câu hỏi).

## Acceptance Criteria

- **FR-3 / scenario:** Given text + đúng 1 đáp án đúng trong ≥2 lựa chọn, when admin `POST /questions`, then câu hỏi lưu thành công, response 201.
- **FR-3 / scenario:** Given options có 0 hoặc >1 đáp án đúng, when tạo câu hỏi, then response 400.
- **FR-3 / scenario:** Given câu hỏi kèm ảnh hợp lệ, when tạo, then ảnh lưu qua Cloudinary, `image_url` có giá trị trong response.
- **NFR-2 / scenario:** Given Cloudinary trả lỗi/timeout (mock), when tạo câu hỏi kèm ảnh, then câu hỏi vẫn lưu thành công (201) với `image_url=None` và `image_upload_warning` trong response.
- **FR-3 / scenario (WARN-3):** Given file đính kèm có MIME-type không phải ảnh (ví dụ `application/pdf`), when tạo câu hỏi, then response 400, không gọi Cloudinary.
- **FR-3 / scenario (WARN-3):** Given file đính kèm >5MB, when tạo câu hỏi, then response 400, không gọi Cloudinary.

## Interface Contract

**Receives from T003:** `require_role("admin")` dependency.
**Produces:** Question records mà T012 (exam assembly) dùng làm `question_id`.

## Technical Details

Validate MIME-type dựa trên nội dung file thực tế (magic bytes) thay vì chỉ tin `Content-Type` header do client gửi, để tránh client giả mạo header.
