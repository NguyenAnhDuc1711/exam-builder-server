# T012: Exam assembly + assignment

## Context

Gộp từ 2 task riêng biệt (assembly + assignment) sau plan-review (RED-1) vì cả hai cùng sửa `app/api/v1/routers/exams.py`, cùng admin-only, và assignment không có giá trị độc lập nếu tách rời khỏi assembly. Task này phụ thuộc T010 vì assignment cần user đã tồn tại trong DB — không parallel hoàn toàn với T010 như T011.

## Description

`POST /exams` ghép đề từ danh sách question_id có thứ tự (validate tồn tại trước khi ghép — WARN-1 từ plan-review). `POST /exams/{id}/assign` gán đề cho user cụ thể (validate user tồn tại, chặn gán trùng).

## Implementation Steps

1. `app/application/use_cases/assemble_exam.py`: nhận `title, question_ids: list[int]` (có thứ tự). Validate TOÀN BỘ `question_ids` tồn tại trong ngân hàng TRƯỚC khi insert — nếu có id không tồn tại, reject 404 kèm danh sách id không tìm thấy (không insert một phần).
2. `app/application/use_cases/assign_exam.py`: nhận `exam_id, user_id`. Validate exam tồn tại (404 nếu không), validate user tồn tại và có role=`user` (404 nếu không), validate chưa có assignment (exam_id, user_id) trùng (409 nếu có — dựa trên unique constraint từ T002).
3. `app/api/v1/routers/exams.py`: `POST /exams` (`require_role("admin")`), `POST /exams/{id}/assign` (`require_role("admin")`), `GET /exams/{id}` (admin xem chi tiết đề).

## Acceptance Criteria

- **FR-4 / scenario:** Given admin chọn N question_id hợp lệ theo thứ tự, when `POST /exams`, then đề lưu với `exam_question` đúng thứ tự.
- **FR-4 / scenario (WARN-1):** Given danh sách question_ids có ít nhất 1 id không tồn tại trong ngân hàng, when tạo đề, then response 404 kèm danh sách id không tìm thấy, KHÔNG có đề nào được tạo (không insert một phần).
- **FR-5 / scenario:** Given exam và user đã tồn tại, when admin `POST /exams/{id}/assign` với user_id đó, then bản ghi assignment tạo thành công, response 201.
- **FR-5 / scenario:** Given exam đã được gán cho user đó rồi, when gán lại lần 2, then response 409.
- **FR-5 / scenario:** Given user_id không tồn tại, when assign, then response 404.

## Interface Contract

**Receives from T003:** `require_role("admin")` dependency.
**Receives from T010:** user đã tồn tại trong DB (endpoint `POST /users` đã chạy trước đó) để dùng làm target assignment.
**Produces:** `exam_assignment_id` — khóa mà T020 dùng để nhận diện bài làm của user.

## Tests to Write

- Ghép đề với toàn bộ question_id hợp lệ → thành công, thứ tự đúng.
- Ghép đề với 1 question_id không tồn tại → 404, verify KHÔNG có `exam`/`exam_question` nào được insert (rollback sạch).
- Assign thành công → 201.
- Assign trùng → 409.
- Assign với user_id không tồn tại → 404.

## Technical Details

Validate question_ids tồn tại bằng 1 query `SELECT id FROM question WHERE id IN (...)` rồi so sánh set kết quả với set đầu vào — tránh N query riêng lẻ cho từng id.
