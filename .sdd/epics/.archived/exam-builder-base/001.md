# T001: Project scaffolding + Docker Compose + Alembic init

## Context

Chưa có gì trong repo ngoài docs/skill — đây là task đầu tiên, mọi task khác phụ thuộc vào cấu trúc thư mục và hạ tầng chạy được từ task này. Không cần đọc epic để bắt đầu: mục tiêu là có một FastAPI app rỗng chạy được qua Docker Compose, kết nối được PostgreSQL, và Alembic sẵn sàng nhận migration.

## Description

Dựng cấu trúc thư mục Clean Architecture (`app/domain`, `app/application`, `app/infrastructure`, `app/api`, `app/core`), `docker-compose.yml` với 3 service (`api`, `postgres`, `pgadmin`), `Dockerfile` cho service `api`, khởi tạo Alembic ở thư mục gốc, và `app/core/config.py` đọc biến môi trường qua Pydantic Settings.

## Implementation Steps

1. Tạo cấu trúc thư mục: `app/domain/{entities,repositories}/`, `app/application/{use_cases,ports}/`, `app/infrastructure/{db/{models,repositories},auth,storage}/`, `app/api/v1/{routers,schemas}/`, `app/core/`. Mỗi thư mục Python có `__init__.py`.
2. Viết `app/core/config.py` dùng `pydantic-settings.BaseSettings`: `DATABASE_URL`, `JWT_SECRET_KEY`, `JWT_ACCESS_EXPIRE_MINUTES=1440`, `JWT_REFRESH_EXPIRE_DAYS=7`, `CLOUDINARY_CLOUD_NAME`, `CLOUDINARY_API_KEY`, `CLOUDINARY_API_SECRET`.
3. Viết `app/main.py` với FastAPI app rỗng + endpoint `GET /health` trả `{"status": "ok"}`.
4. Viết `Dockerfile` (Python 3.12-slim, cài dependencies từ `requirements.txt`/`pyproject.toml`, chạy `uvicorn app.main:app`).
5. Viết `docker-compose.yml`: service `postgres` (image `postgres:16`, volume, healthcheck `pg_isready`), service `api` (build từ Dockerfile, `depends_on: postgres: condition: service_healthy`, env từ `.env`), service `pgadmin` (image `dpage/pgadmin4`, port map).
6. Chạy `alembic init alembic` ở thư mục gốc, sửa `alembic/env.py` để đọc `DATABASE_URL` từ `app.core.config`.
7. Tạo `.env.example` liệt kê toàn bộ biến môi trường cần thiết (không commit `.env` thật).

## Acceptance Criteria

- **NFR-4 / scenario:** Given máy sạch có Docker, when chạy `docker-compose up -d`, then cả 3 service khởi động thành công và `curl localhost:8000/health` trả 200 trong vòng 60 giây.
- **NFR-4 / scenario:** Given `alembic.ini` đã cấu hình, when chạy `alembic current`, then lệnh chạy thành công không lỗi kết nối DB (dù chưa có migration nào).

## Tests to Write

- Smoke test: `docker-compose up -d && curl -f localhost:8000/health` (dùng trong CI job, cũng là cơ sở cho SC-5).

## Technical Details

Dùng `pydantic-settings` (Pydantic v2) thay vì `python-dotenv` thủ công để có validation kiểu dữ liệu ngay khi load config — tránh lỗi runtime muộn nếu thiếu biến môi trường.
